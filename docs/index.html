FCL Logistics: kiểm thử tự động

Dự án tự học về kiểm thử phần mềm, thực hiện trên một hệ thống quản lý vận tải container nguyên (FCL). Gồm kiểm thử API, giao diện và luồng xuyên suốt, viết bằng Playwright và TypeScript.

Trang này tập hợp báo cáo chạy test, tài liệu test case và mã nguồn. Framework dùng Page Object Model, data-driven testing và kiến trúc phân tầng Core, Service, Assertion cho phần API.

Nghiệp vụ được kiểm thử

Giá mua cước từ nhà cung cấp được duyệt, dùng để lập bảng phân tích giá bán, trở thành bảng giá cho khách và cuối cùng sinh ra đơn đặt hàng.

  1. Giá muaFCL Buying Giá nhà cung cấp báo, qua bước gửi và duyệt
  2. Bảng phân tíchFCL Quotation Tính giá bán và lợi nhuận
  3. Bảng giáFCL Rate Card Giá áp dụng cho khách, cần duyệt
  4. Đơn đặt hàngFCL Booking Sinh ra khi chuyển đổi từ bảng giá

Báo cáo kiểm thử

Mỗi báo cáo là báo cáo HTML của Playwright: kết quả từng test, các bước thực hiện và dữ liệu đính kèm.

  • API

    Price FCL Buying API Tests

    Tạo giá mua FCL qua API: dữ liệu hợp lệ, thiếu trường bắt buộc, sai kiểu dữ liệu, giá trị không hợp lệ và trùng bản ghi.

  • API

    Price Toll Buying API Tests

    Tạo giá vé cầu đường qua API: dữ liệu hợp lệ, thiếu trường bắt buộc, định dạng sai, mã tham chiếu không tồn tại và trùng bản ghi.

  • UI

    FCL Booking UI Tests

    Tạo đơn đặt hàng trên giao diện: lưu thành công, báo lỗi trường bắt buộc và quy tắc ngày giờ, đối chiếu dữ liệu ở danh sách, chi tiết và form sửa.

  • E2E

    Convert Booking From Price Buying FCL E2E Tests

    Luồng xuyên suốt từ giá mua đã duyệt, qua bảng phân tích và bảng giá, đến đơn đặt hàng.
